# Feature literature search strategy

Search date: 2026-06-01

Purpose: identify stronger supporting literature for the implemented FAA VR map prototype features and replace the first-pass feature matrix with a better feature-to-literature traceability table.

## Review question

Which academic papers best support or inform the design of the current prototype features: WebXR/browser platform, staged FAA map data, layered and interactive airspace visualization, altitude depiction, VORTAC-related chart content, controller-based map manipulation, linked desktop review, asymmetric instructor-trainee collaboration, synchronized highlighting/layer state, and planned evaluation measures?

## Inclusion criteria

- Peer-reviewed paper, book, systematic review, framework paper, or credible technical research report.
- Directly supports at least one implemented feature, design decision, or evaluation measure.
- Prioritizes ATC/aviation, immersive learning, asymmetric VR collaboration, geospatial VR, 3D interaction, or human factors.
- Provides enough metadata to cite in a workshop paper.

## Exclusion criteria

- Commercial product pages without scholarly evidence.
- Reddit posts, marketing pages, or unsourced commentary.
- Papers with only loose keyword overlap.
- Sources that support future features only, unless they directly inform evaluation planning.

## Search clusters used

- ATC 2D/3D visualization: `air traffic control 3D visualization situation awareness workload`, `2D 3D air traffic control visualization user study`, `4D interface air traffic control`.
- Existing project baseline: `immersive VFR 3D map visualization air traffic control Patrick Lee Desmit Carter`.
- Asymmetric collaboration: `asymmetric VR PC collaboration`, `asymmetric virtual reality desktop instructor student`, `symmetric asymmetric VR collaboration task performance`, `teacher student asymmetric mixed reality`.
- Shared reference and linked sessions: `TransceiVR`, `WebTransceiVR`, `VR non-VR browser collaboration`.
- Geospatial VR and layered maps: `multilayer geospatial data virtual reality`, `interactive 3D maps virtual reality`, `geospatial networks visualization survey`.
- 3D interaction: `VR grabbing manipulation techniques Bowman Hodges`, `3D user interface design selection manipulation system control`.
- Immersive learning and evaluation: `CAMIL immersive learning self-efficacy cognitive load`, `VR higher education systematic review`, `collaborative learning immersive virtual reality systematic review`, `NASA-TLX workload`.
